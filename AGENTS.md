# Project

React + TypeScript + Vite website

# Goals

- Improve mobile performance
- Preserve current design
- Improve SEO indexability
- Make minimal safe changes

# Commands

- install: npm install
- dev: npm run dev
- build: npm run build
- lint: npm run lint

# Rules

- Do not rewrite entire sections unless necessary
- Prefer minimal patches
- Do not add dependencies unless justified
- Preserve existing styling and behavior
- Explain root cause before changing code

# Focus areas

- Reduce unused JavaScript
- Improve lazy loading and code splitting
- Check canonical/meta/rendering issues on challenge pages
- Keep accessibility improvements incremental

# Done means

- Project builds successfully
- No TypeScript errors
- No lint regressions
- Explain changed files and why
